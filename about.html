About TruthLens AI

TruthLens AI is an advanced multi-modal authenticity detection framework developed to evaluate digital content trustworthiness in both Marathi and English languages. It supports multiple formats including text news, social media links, image screenshots, and video metadata.

Created by Shrutika Sonmale as a capstone digital trust solution to combat regional misinformation, edited screenshots, viral fake claims, and AI-manipulated content.

Core Capabilities / मुख्य वैशिष्ट्ये

🌐 Multilingual NLP (मराठी + English)

Analyzes news articles and WhatsApp forwards in Marathi and English to detect clickbait patterns, deceptive headlines, and misleading claims.

🔍 Live Fact-Check Verification

Integrated with Google Fact-Check Tools API to instantly match claims against verified databases from trusted fact-checking organizations.

🖼️ Image Forensics & Marathi OCR

Combines Tesseract OCR (Marathi + English) with Error Level Analysis (ELA) to extract embedded text and detect Photoshop or pixel manipulations in screenshots.

🎥 Video & Reels Forensics

Performs temporal frame variance and inconsistency checks using OpenCV to flag deepfakes and manipulated video files.

Technology Stack

  • Backend Engine: Python, Flask, Flask-CORS
  • OCR & Image Processing: Tesseract OCR (Marathi & English dataset `mar+eng`), PIL, NumPy
  • Computer Vision & Video Forensics: OpenCV (Frame-by-Frame Temporal Variance)
  • APIs & Web Scraping: Google Fact-Check Tools API, BeautifulSoup4
  • User Interface: HTML5, Responsive CSS Glassmorphic Design, JavaScript
